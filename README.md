# 千年帝国的最后一息 · TNO 策略游戏

> 基于 TNO（The New Order: Last Days of Europe）架空世界观的网页策略游戏。
> 时间跨度 1962 — 2000，共 156 回合。

⚠ **声明**：本游戏基于 TNO 架空世界观创作，纯属虚构历史推演。游戏内容旨在探讨极权主义的后果与历史教训，绝无任何政治立场或意识形态宣传意图。游戏中所有人物、事件、国家均为虚构，与现实无关。

## 在线游玩

部署到 GitHub Pages 后，访问：

```
https://<你的用户名>.github.io/tno-strategy-game/
```

## 本地运行

无需后端，直接用浏览器打开 `index.html` 即可。或启动本地服务器：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000/
```

## 游戏特性

- **时间跨度**：1962Q1 — 2000Q4，共 156 回合
- **工业系统**：8 种民工业 + 9 种军工业建筑，玩家自主设计工业体系
- **威慑系统**：综合威慑与核威慑，影响外交与结局
- **5 条路线**：施佩尔（改革派）/ 鲍曼（保守派）/ 戈林（军国派）/ 海德里希（党卫军）/ 斯派达尔（意外）
- **15 种结局**：从民主化改革的"帝国之春"到核子末日的"诸神黄昏"
- **剧情事件链**：登月庆典、希特勒之死、德国内战、勃艮第危机、核军备竞赛、1989 核危机等

## 操作说明

- 点击"进入帝国总理府"开始游戏
- 点击右侧"推进至下一季度"按钮推进时间（或按空格键）
- 在"工业建设"标签页建造建筑
- 在"国策政策"标签页调整政策
- 在"科技研发"标签页研发科技
- 响应事件弹窗中的抉择，每个选择都将影响帝国命运

## 技术栈

纯原生 HTML / CSS / JavaScript，无任何依赖，无需构建。
